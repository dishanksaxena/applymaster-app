# ApplyMaster — Resume Here

**What it is:** Next.js 14 full-stack hiring platform with AI-powered resume parsing, Stripe payments, Supabase auth, Mapbox geospatial, 3D visualization.

**Tech Stack:**
- Next.js 14 (React 18, TypeScript, Tailwind)
- **Anthropic SDK** for AI (resume parsing)
- Stripe (payments)
- Supabase (auth + database)
- Mapbox GL (job location maps)
- Three.js (3D charts)
- Framer Motion (animations)
- PDF parsing (mammoth, pdf-parse, pdfjs-dist)

**Quick Start:**
```bash
npm install
npm run dev          # Dev server on :3000
npm run build        # Production build
```

**Key Files:**
- `src/` — frontend components + API routes
- `.supabase/` — database migrations
- `PHASE2_SETUP.md` — next phase documentation
- `PRODUCTION_UI_GUIDE.md` — UI standards
